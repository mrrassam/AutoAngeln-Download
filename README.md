# AutoAngeln – Download

**Neueste Version herunterladen:** rechts bei **„Releases“** → oberste Version →

| System | Datei |
|---|---|
| Windows | `AutoAngeln.exe` – herunterladen und doppelklicken (keine Installation nötig) |
| Mac | `AutoAngeln.dmg` – öffnen und AutoAngeln in „Programme“ ziehen |

**Updates:** Die App prüft beim Start, ob es eine neue Version gibt. Dann oben auf **„⬆️ Update“** klicken – fertig.
Abläufe, Bilder und Einstellungen bleiben dabei erhalten.

**Windows-Warnung „Windows hat den PC geschützt“:** „Weitere Informationen“ → „Trotzdem ausführen“.
